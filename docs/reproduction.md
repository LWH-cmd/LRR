# Reproduction and final-data binding

## Frozen evidence

The final manuscript package is `LRR_APPENDIX_FINAL_OVERLEAF.zip` with SHA256 `b8aee723bf7cd078ed01dd36e93ccb0cd4ecb84268ce961e74d374c3fcf46bad`. The seven files listed in `manifests/paper_version.json` are copied byte-for-byte from its `data/` directory, including the final 1326-row benchmark seed table and 282-row component table. Those files span all deletion ratios; the appendix's printed 2.5% subset is not the public-data scope. Additional table excerpts preserve the manuscript's literal sensitivity, parameter and runtime values. No observed records were regenerated or inferred from aggregate numbers.

Source fingerprints were checked against the final manuscript's existing provenance ledger (`manifests/paper_source_checks.json`), not by re-evaluating all scientific groups. No full-budget training replay is claimed by this source-binding check.

## From raw data

`prepare_dataset.py` uses CitationFull Cora and DBLP feature matrices, the registered 5% validation / 5% test split, and the exact exported frozen homogeneous split indices. WN18RR uses its predefined raw train/validation/test splits and 11 base / 22 propagation relations. `pretrain.py` provides Original GCN/GAT/RGCN stages with 2000-epoch recipes; all method-stage paths are portable. The GAT model and negative child seeds are copied from the formal per-seed configs. Fresh stochastic pretraining can differ numerically across environments; use the published hash-pinned Originals to replay the paper's actual checkpoint lineage.

`build_bundle.py` restores homogeneous requests from exact exported requested-edge indices. RGCN retains its registered native seeded construction. Both branches retain their native graph/support rules, static pools and 500 retained positive evaluation controls. GCN uses the native directed support construction and undirected retained propagation. GAT uses undirected support and directed runtime propagation; its online Forget key is GAT while the Retain stream inherits the formal Common-GCN domain/key. Retain samples are deterministically generated by the pinned PyG 2.6.1 helper per update instead of downloading multi-GB frozen NPY schedules. The paper's immutable historical data remain separate.

RGCN uses frozen-teacher Forget references, relation-wise head permutations and the update-zero-relative constrained selector described in Appendix A. The main paper's compact common loss notation does not override the registered RGCN branch. Homogeneous updates are 3000 with validation every 100; RGCN updates are 1600, GraphSAINT 1024/walk2/32, candidates 0, 8..64 by 8, then 128..1600 by 64.

## Validation boundary

This release is checked for final-source binding, file hashes, syntax/import/CLI interfaces and small synthetic preparation/pretraining/update checks. Complete 138-cell training, native baseline retraining and full 2000-epoch pretraining were not rerun. No timing result from synthetic checks is a formal runtime measurement.

The working environment is Python 3.10, PyTorch 2.7.0+cu126, PyG 2.6.1 and matching torch-sparse. Install the CUDA/PyTorch and PyG extension wheels appropriate for your machine before the remaining requirements. Linux/macOS whole-matrix training was not independently validated. Source data and fresh run outputs must never overwrite `results/paper/`.

## Controls

`run_controls.py` runs the eight registered spatial/layer/distance profiles on Cora/GCN/Ed_IN/2.5%, with each seed's matched inputs. The final A/B/C formulation observations and original source records are included separately. Sensitivity and runtime table excerpts preserve the literal final-paper numbers; no new experiments are claimed.
