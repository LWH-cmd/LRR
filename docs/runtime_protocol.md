# Formal training wall-clock

The runtime scripts measure **wall-clock time for method-specific training/update plus the method-native validation and model-selection procedure**. They load the config, tensor bundle and pretrained checkpoint and prepare static tensors and samplers before starting the timer. The timed interval includes training, scheduled validation and in-memory selector work. Final test evaluation, logging and result serialization occur after the timer.

No hardware-specific seconds are encoded as expected runtimes.

## GCN

- 3000 updates by default, Adam at `3e-4`, weight decay `0`.
- A fresh zero-initialized FullRank repair is used for each run.
- Forget negatives are sampled per update from the configured full training propagation-edge universe with the formal role seed.
- Validation runs every 100 updates (30 points); the selector maximizes validation J-AUC and keeps the earlier update on ties.
- The first frozen GCN representation, retained graph normalization and static edge groups are prepared once. Six student scoring groups are decoded together inside each update.

## GAT (Cora / CitationFull DBLP)

- COMMON-GAT-v1: two single-head GATConv layers, 128/64 outputs, ReLU between layers, self loops, attention dropout 0, frozen dot-product decoder. Only the two zero-initialized FullRank repair matrices are trained (20,480 parameters).
- Adam `3e-4`, weight decay 0; 3000 updates, validation every 100 updates. Layer-1 native output is cached because the original backbone is frozen and dropout is zero.
- Online Forget negatives use the exact GAT sampling identity and the formal directed `full_d` exclusion domain. Retain negatives keep their registered inherited GCN identity and exclusion domain. The active preparation path uses that role-seeded representation without the historical precomputed shard files; do not substitute a GAT identity.
- The S6 selector compares validation `(DT_AUC + Df_AUC, DT_AUC, Df_AUC, -retain_mse, -validation_total_loss, -epoch)` lexicographically with tolerance `1e-12`. As in the source, `validation_total_loss` is the most recent pre-update training loss. DT metrics use sigmoid scores; Df metrics use logits.
- Output `selected_update` is one-based; `selected_epoch` is the source's zero-based epoch. No GAT runtime benchmark or timing wrapper is provided.

## RGCN + DistMult

- 1600 updates by default: 50 rounds × 32 GraphSAINT batches, 1024 start nodes and walk length 2.
- The Windows-safe random-walk backend changes only the low-level random-walk implementation. GraphSAINT start sampling, walk transitions, unique-node collection, induced subgraphs, normalization and relation IDs are retained.
- Requested triples and their reverse relation copies are excluded from message passing.
- The Forget reference is the frozen original teacher's negative score.
- Selector candidates are update `0`, `8..64` by 8, then `128..1600` by 64. Feasible points satisfy `DT_AUC >= DT0 - 0.010`; the selector maximizes `Df_AUC`, with earlier update winning ties.

## Serialized bundle fields

All fields below are tensors unless stated otherwise. Preprocessing must bind the intended formal request and controls; the release does not generate replacement protocol assets.

Every config also includes `sampling_identity` (`dataset`, `backbone`, `deletion_mode`, `deletion_ratio`, `run_seed`). These values are the exact strings used by the formal role-seed identity and are kept separate from display labels such as `Ed_IN`; provide the values recorded with the input bundle rather than deriving them from display names.

### GCN bundle

- `model`: `input_dim`, `hidden_dim`, `output_dim`, `input_mode`; optionally `num_nodes` for `node_id_embedding`.
- `backbone_state_dict`: optional when `pretrained_checkpoint_path` is provided.
- `training`: `x`, `full_train_mp_edge_index`, `dr_mp_edge_index`, `support1`, `support2`, `gate1`, `gate2`, `df`, `local`, `retain_positive`, `anchor`, `retain_negative_schedule`.
- `retain_negative_schedule`: the `role_seeded_retain_v1` descriptor generated by `scripts/build_bundle.py`, with the registered identity, graph domains and update shape. It generates the required per-update Retain stream without archived NPY files.
- `validation`: `positive`, `negative`, `requested`, `retained_control_groups` with shapes `[2,P]`, `[2,Q]`, `[2,D]`, `[500,2,M]`.

The trainer derives frozen Local and Anchor target probabilities once from the loaded original backbone. All edge tensors refer to node rows in `x`.

### GAT bundle

The graph, support, supervision, schedule and validation fields use the same names as the GCN bundle. `model` contains `input_dim` and `architecture_version: COMMON-GAT-v1`; `x` is a floating feature matrix. Also supply `training.teacher_local_probability` and `training.teacher_anchor_probability` from the formal GAT teacher assets. Optional `test` has the same four fields as `validation`. The bundle builder includes `sampling_identity` and checkpoint/source identities; trainers reject a mismatching run identity.

Control groups are stored as `[500,2,M]`. Decoding flattens them with `permute(1,0,2).reshape(2,-1)` so that every source stays paired with its target; the same ordering applies to RGCN control relations.

### RGCN bundle

- `model`: `num_entities`, `base_relations`; optional `embedding_dim`, `hidden_dim`, `output_dim` (paper-main values are 128/128/64).
- `backbone_state_dict`: optional when `pretrained_checkpoint_path` is provided.
- `graphsaint_data`: PyG `Data` containing global node IDs in `x`, training `edge_index`, `edge_type`, and aligned boolean `df_mask`/`dr_mask`. Both direction copies are represented; request copies are marked in `df_mask` and excluded from propagation by `dr_mask`.
- `training`: `df`, `df_type`, `local`, `local_type`, `retain_positive`, `retain_type`, `anchor`, `anchor_type`, `support1`, `support2`, `gate1`, `gate2`.
- `validation`: `x`, retained `edge_index`/`edge_type`, `gate1`, `gate2`, `val_positive`, `val_negative`, `val_relation`, `requested`, `requested_relation`, `retained_control_groups` `[500,2,M]`, and `retained_control_relations` `[500,M]`.

Relation IDs on reverse copies follow the doubled relation vocabulary `r + base_relations`. Validation edge/relation arrays and control positions must already reflect the formal evaluation split.

## Commands

`runtime_gcn.py` and `runtime_rgcn.py` write only the timing summary; `run_gcn.py` and `run_rgcn.py` also save the selected FullRank repair state and validation trajectory. Runtime output paths default to a `.json` record beside the configured output path.
